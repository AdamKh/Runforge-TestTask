# Runforge

Тестовое задание: страница со списком пробежек. Есть поиск по названию, фильтры и сортировка, состояния загрузки, ошибки и пустого результата.

## Демо

Развёрнутая версия: https://your-project.vercel.app

## Стек

- React 19 + TypeScript
- Vite
- Ant Design
- CSS Modules
- MSW (Mock Service Worker) для мок-API
- ESLint + Prettier

## Требования

- Node.js `^20.19.0` или `>=22.12.0`
- npm

## Установка и запуск

```bash
git clone https://github.com/AdamKh/Runforge-TestTask.git
cd Runforge-TestTask

npm install
npm run dev
```

После запуска откройте адрес, который выведет Vite в терминале (обычно http://localhost:5173).

Отдельный бэкенд не нужен: запросы к API перехватывает MSW прямо в браузере.

## Скрипты

| Команда           | Что делает                                         |
| ----------------- | -------------------------------------------------- |
| `npm run dev`     | Запуск dev-сервера с мок-API                       |
| `npm run build`   | Проверка типов и сборка в папку `dist` (без моков) |
| `npm run preview` | Просмотр собранной версии (данные не загрузятся)   |
| `npm run lint`    | Проверка кода ESLint                               |

## Тестирование

Тестирование происходило вручную в браузере. Проверил сценарии:

### 1. Поиск по названию

1. Дождаться загрузки списка;
2. В строку поиска ввести "e2e";
3. Убедиться что отобразились все запуски с "e2e" в названии без учета регистра.

### 2. Фильтрация по статусу

1. Дождаться загрузки списка;
2. В фильтрах выбрать значение "Running";
3. Убедиться что отобразились все запуски с status: "running";
4. В фильтрах выбрать еще 1 значение "Failed";
5. Убедиться что отобразились все запуски с status: "running" или "failed";
6. Очистить фильтры и убедиться что отобразились все запуски.

### 3. Сортировка

1. Дождаться загрузки списка;
2. В сортировке выбрать значение "Newer";
3. Убедиться что запуски отсортировались по убыванию полю createdAt;
4. В сортировке выбрать значение "Longer";
5. Убедиться что запуски отсортировались по возрастанию полю durationSeconds.

### 4. Открытие деталей

1. Дождаться загрузки списка;
2. Нажать на кнопку "Details" на карточке запуска;
3. Убедиться что появился popover с подробной информацией запуска.
